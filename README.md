I am a big fan of Animals and I am creating a pet website where I can connect animal lovers with their perfect companions. With pet ownership on the rise, I am building a platform that makes finding,
buying, and caring for pets as easy as possible. I am currently working on the following features mentioned below:


Browse & Buy — to help you find perfect match.

Foster a Disabled Pet — Able to give a disabled pet a home.

Built With Security in Mind — I will be including robust security features to protect personal data and I will be using JWT instead of session based as my security.

User-Friendly Design — Clean, accessible, and easy to navigate throught website.

Reliable & Well-Tested — using tested APIs like Postman to check endpoints to ensure smooth, dependable performance across every feature.

I will be using secure cloud storage on AWS, including EC2 for hosting and S3 for file storage, along with other AWS services as needed.
